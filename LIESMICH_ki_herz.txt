SO BINDEST DU ES EIN (auf den User-Seiten: gastro/shopping/nachtleben/events/Profile)
  Direkt nach dem supabase-js Script:
    <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
    <script src="sp-track.js"></script>

  Herz-Button (Bookmark) an einer Karte:
    <button onclick="toggleHerz(this,'location','<LOCATION_ID>','gastro',4)">🤍</button>
    <script>
    async function toggleHerz(btn,typ,id,kat,kreis){
      const r=await spBookmarkToggle(typ,id,{kategorie:kat,kreis:kreis});
      if(!r.ok && r.reason==='login'){ location.href='login.html'; return; }
      btn.textContent = r.bookmarked ? '❤️' : '🤍';
    }
    </script>

  View loggen (wenn ein Profil geöffnet wird, z.B. in gastro-profil.html):
    spTrack('view_profile','location', loc.id, {kategorie:loc.kategorie, kreis:loc.kreis, tags:loc.stimmung_tags});

  Filter/Suche loggen:
    spTrack('filter', null, null, {meta:{kreis:gewählterKreis, offe:true}});
    spTrack('search', null, null, {meta:{q: sucheText}});

WICHTIG
  - Bookmarks/Interactions sind pro eingeloggtem User (Supabase Auth, RLS).
  - Anonyme Besucher können Views loggen (user_id=null) — zählt für "angesagt", nicht für die persönliche DNA.
  - Nichts blockiert die Seite: alle Calls sind fire&forget, Fehler werden still geschluckt.
