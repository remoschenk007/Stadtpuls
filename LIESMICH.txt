STADTPULS · Auto-Sync einrichten (Events + Locations, täglich automatisch)
==========================================================================

Damit musst du NIE wieder lokal ein Script laufen lassen oder import.html öffnen.
Die GitHub Action holt Events (Eventfrog) + Locations (Zürich Tourismus)
jeden Morgen automatisch — neue rein, alte raus, featured bleibt sicher.

DATEIEN (wohin):
  import_eventfrog.py            -> Projektordner (stadtpuls/)
  import_locations.py            -> Projektordner (stadtpuls/)
  .github/workflows/stadtpuls-sync.yml  -> NEU unter .github/workflows/

EINRICHTEN (3 Schritte, einmalig):

1) Dateien ins Repo + pushen:
   cd ~/Downloads && unzip -o stadtpuls-autosync.zip -d autosync && \
   cp -R autosync/. /Users/alessandrachristen/stadtpuls/ && \
   cd /Users/alessandrachristen/stadtpuls && \
   git add import_eventfrog.py import_locations.py .github/workflows/stadtpuls-sync.yml && \
   git commit -m "Auto-Sync: Eventfrog + Zürich Tourismus, täglich" && \
   git pull --rebase origin main && git push origin main

2) GitHub-Secret setzen (für das Löschen alter Events):
   GitHub -> dein Repo -> Settings -> Secrets and variables -> Actions
   -> New repository secret
   Name:  SUPABASE_SERVICE_KEY
   Wert:  dein service_role-Key (Supabase -> Settings -> API)

3) Erstmals auslösen (macht sofort den ersten Lauf, in der Cloud):
   GitHub -> dein Repo -> Tab "Actions" -> "Stadtpuls Daten-Sync"
   -> "Run workflow" -> Run

   Ab dann läuft es täglich um ~06:00 von selbst. Fertig.

HINWEIS: import.html mit dem kaputten corsproxy brauchst du nicht mehr.
